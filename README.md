# flexnav

This repo originally held an unrelated jQuery plugin (`legacy-flexnav/`,
kept below for reference). The NHS Top Up proposal site was mistakenly
built inside it later — since `flexnav` is a **public** repo, that meant
an internal charity business plan sat in public git history.

**NHS Top Up has moved** to the private [`Jon3/NHSTopUp`](https://github.com/Jon3/NHSTopUp)
repo, which is now its correct, canonical home. Nothing NHS Top Up-related
belongs in this repo going forward.

## legacy-flexnav/

The original content of this repo — an unrelated legacy jQuery plugin, kept
